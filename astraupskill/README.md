# From beginner Java CLIs to code that holds up

The numbered modules in `bootcamp/` teach one idea per file. These
chapters step back and connect them: how to study with this repository,
and the handful of ideas that keep reappearing across the modules.
They are prose, meant to be read slowly, and they are the source material
for review questions about the track.

| chapter | what it is for |
| --- | --- |
| [01-START-HERE](01-START-HERE.md) | how the repository works, how to run and verify, how to study |
| [02-CONCEPTS](02-CONCEPTS.md) | the seven ideas the exercises keep returning to, and why |
| [03-SYSTEM-DESIGN](03-SYSTEM-DESIGN.md) | how to approach a design question, and how modules 09–13 combine into classic designs |

Read 01 before your first exercise. Read 02 after module 04, and again
after module 08 — it will mean more the second time.

Read 03 once before module 09 for the map, and again after module 13,
when every box in its diagrams is something you have built.
